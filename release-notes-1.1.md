# Matte V1.1 — Silver Gate (Insider)

Insider build with the newest Matte features.

## New in V1.1
- URL-launch support: run `Matte.exe https://example.com` to open any site straight on startup (the "opening site" feature)
- Everything from V1 Silver Gate: multi-tab browsing, smart omnibox, progress bar, custom title-bar controls

## Install
Download **Matte-Setup-1.1.0.exe** and run it.
