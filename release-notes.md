# Matte V1.2 — Silver Gate

Regular update to Matte, featuring **Jarvis** and a completely redesigned top bar.

## New in V1.2
- Jarvis assistant: type `jarvis go to youtube`, `jarvis search cats` or any natural command in the address bar and Matte navigates for you
  - Fast local command parser for common commands (20+ built-in sites)
  - Falls back to the api.navy AI service for complex commands (toggle in Settings)
  - Animated JARVIS indicator appears while it works
- Redesigned top bar: dedicated tab strip with rounded top tabs, glowing active tab, loading spinner dot per tab, close-on-hover, middle-click to close tabs, edge fade on overflow
- Version bumped to 1.2.0

## Install
Download **Matte-Setup-1.2.0.exe** and run it.

Built on Electron
